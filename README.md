**Project Documentation**

*Design Choices*
The layout was designed using Flexbox and Grid to ensure a responsive and adaptable structure for different screen sizes. A clean, modern aesthetic was chosen, with a dark theme featuring black static sections, white content, and orange hover effects for navigation links and icons. Tables have square cells with equal spacing and a hover effect to enhance readability. Animations and transitions were implemented for smooth UI interactions.

*JavaScript Features*
Form Validation: Ensures user input meets specified criteria before submission.
Interactive Elements: Includes toggle buttons, dropdown menus, and dynamic content updates to improve user experience.
Smooth Scrolling & Animations: Provides a polished feel when navigating through sections.

*Challenges & Solutions*
One challenge was ensuring full responsiveness across various screen sizes. By carefully adjusting media queries, fine-tuning margins, and testing across multiple devices, a seamless user experience was achieved.

*Deployment Process*
The project was deployed using Netlify, ensuring easy access and version control. The final version was tested thoroughly before deployment to ensure functionality across different browsers.

Link to live website: https://ronny-scott-personal-portfolio.netlify.app/
